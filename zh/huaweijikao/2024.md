### 找座位

**题目描述**

一排座位用 0/1 数组表示：1 表示该座位已有人，0 表示空位。一个人坐下时要求其左右相邻的座位都不能有人（最左/最右的座位只需一侧相邻座位为空）。给定座位数组，求最多还能坐下多少人。

**示例**

```text
输入: [1, 0, 0, 0, 1]
输出: 1

输入: [1, 0, 0, 1, 0, 0, 1]
输出: 0
```

### 停车场数量统一

**题目描述**

停车场的车位状态用 0/1 数组表示：1 表示该车位被车辆占用，0 表示空位。连续被占用的车位视作停放着的车辆，且三种车辆分别占用 3、2、1 个车位。为使车辆数量统一且最少，每一段连续的 1 应优先按 3 个车位停一辆，再按 2 个车位停一辆，最后按 1 个车位停一辆。求整个停车场最少需要多少辆车。

**示例**

```text
输入: [1, 1, 1, 1, 1, 1, 0, 1]
输出: 3
```

说明：前 6 个连续车位可停 2 辆（3+3），最后 1 个车位停 1 辆，共 3 辆。

### 找山峰数量

**题目描述**

地图用一维数组表示：数组索引代表水平位置，元素代表相对海拔高度，元素 0 代表地面。一座山峰指高度同时大于左右相邻位置的高度；数组边界外视为高度 0（地面），边界处高度大于相邻高度也算山峰。一个山脉可能有多座山峰，求地图中山峰的总数。

**示例**

```text
输入: [0, 1, 4, 3, 1, 0, 0, 1, 2, 3, 1, 2, 1, 0]
输出: 3
```

说明：三座山峰分别为高度 4（索引 2）、高度 3（索引 9）、高度 2（索引 11）。

### 爱吃蟠桃的孙悟空

**题目描述**

蟠桃园有 N 棵桃树，每棵树上桃子数量已知，守卫将在 H 小时后回来。孙悟空可以决定吃桃速度 K（个/小时）：每小时选一棵桃树吃掉 K 个，若树上桃子少于 K 个则全部吃掉，且该小时剩余时间不再吃。求能在 H 小时内吃完所有桃子的最小整数速度 K；若任何速度都吃不完（桃树数多于 H，每小时只能吃一棵树），返回 0。

**示例**

```text
输入: 桃树 [2, 3, 4, 5]，H = 4
输出: 5
```

说明：4 棵树恰好在 4 小时内吃完，每小时一棵树，K 必须不小于最大树上的 5 个桃子。

### 部门人力分配

**题目描述**

部门有 N 个任务，每个任务需要的工作量（人日）已知，要求在至多 h 天内全部完成。每天最多处理两个任务（一个任务可单独一天完成），且同一天处理的任务工作量之和不能超过每日上限 x，任务不可拆分。求满足条件的最小每日工作量上限 x。

**示例**

```text

输出: 5
```

说明：x = 5 时可 3 天完成（2+3、4、5）；x = 4 时需要 4 天，不满足 h = 3。
